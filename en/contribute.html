Missing a term? Add it.

Every term lives in one file, tools/terms.mjs, in three languages. Add yours in four steps.

The code is on GitHub: github.com/ElFarisssaid19/qamous-dev

  1. Fork the repo on GitHub, then clone your fork.

    git clone https://github.com/<you>/qamous-dev.git

  2. Add your term to tools/terms.mjs, in Arabic, French and English.

  3. Rebuild the pages.

    node tools/build.mjs

  4. Commit, push and open a pull request.

    gh pr create
