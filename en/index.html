API? Like the café waiter.

40 programming terms, explained with scenes from Moroccan life and real code.

Basics

VariableGot it Like the sugar jar in the kitchen

Like the sugar jar in the kitchen: the label says “sugar”, and when it runs out you refill it. The name stays, the contents change.

A variable is a named place in memory that holds a value, so you can use it again later. You can change its value whenever you need to.

FunctionGot it Like the msemmen seller

Like the msemmen seller at the souk: you hand over the dough (the input) and get back a msemmen (the output). You don’t need to know how she makes it.

A function is a named set of instructions. You write it once, then call it as many times as you like, with different values.

LoopGot it Like the water seller in Jemaa el-Fna

Like the water seller in Jemaa el-Fna: he goes from person to person, pours each one a cup, and stops when the waterskin is empty.

A loop repeats the same work many times without rewriting the code. It stops when the items run out or a condition turns false.

ArrayGot it Like the seats of a grand taxi

Like the seats of a grand taxi: every seat has a number, and the first one, next to the driver, is seat 0.

An array is an ordered list of values in a single variable, each with a number (its index). The index starts at 0, not 1.

BugGot it Like the shopping list missing a word

Like sending someone to the corner shop with a list that says “2 potatoes” when you meant 2 kilos: they come back with two potatoes. They did what you wrote, not what you meant.

A bug is a mistake in the code that makes the program do something you didn’t expect. Debugging is the work of finding its cause and fixing it.

Async/awaitGot it Like clothes at the dry cleaner’s

Like leaving your clothes at the dry cleaner’s: you don’t sit there waiting. You go and do something else, and they call you when it’s ready.

Async/await lets you wait for something slow (such as a server response) without freezing the whole program. “await” means: pause here until the result arrives.

Git

GitGot it Like the class logbook at school

Like the class logbook at school: every lesson is written down with its date. Miss a week, open the logbook, and you know exactly where the class stopped.

Git is a tool that records every change you make to your code. You can go back to any earlier version and work with others on the same project without overwriting each other’s work.

RepositoryGot it Like the family photo album

Like the family photo album: it holds today’s photos and old ones, all in order, and anyone in the family can keep their own copy.

A repository (repo) is the project folder together with the full history Git keeps for it. There is a local repo on your computer and a remote one on GitHub or GitLab.

CommitGot it Like a photo of the tagine at each step

Like photographing your mother’s tagine at every stage: vegetables in, meat added, ready to serve. If it burns later, you know where to go back to.

A commit is a snapshot of your code at a given moment, with a message explaining what changed. Each commit has its own ID, and you can return to it whenever you want.

BranchGot it Like a side alley in the old medina

Like a side alley in the old medina: you leave the main street, wander down the alley, then come back to the same street. The main street hasn’t changed.

A branch is a separate line of work, apart from the main code (main). You try a new feature on it without breaking the version that works.

MergeGot it Like two seamstresses on one caftan

Like two seamstresses working on the same caftan: one does the sleeves, the other the front, and at the end the pieces are joined. If both stitched the same spot, someone has to decide.

Merge brings the work of one branch into another. If both sides changed the same lines, Git stops and asks you to choose (a merge conflict).

Pull requestGot it Like a request to the moqaddem

Like handing a request to the moqaddem, the neighbourhood official: he looks it over, maybe sends it back with corrections, and once everything is in order he signs it.

A pull request (PR) is a request on GitHub to bring your branch’s work into main. Teammates read the code, leave comments, and then approve it.

CloneGot it Like grandma’s harira recipe

Like copying your grandmother’s harira recipe down to the last detail: now you have your own copy to change as you like, and the original stays with her.

Clone downloads a full copy of a repo from GitHub to your computer, with its entire history, so you can work on it locally.

Web and API

HTTPGot it Like a letter at the post office

Like a letter at the post office: it carries an address (the URL), a kind of request (GET or POST) and its contents, and the reply comes back in another letter.

HTTP is the protocol a browser uses to talk to a server. The browser sends a request (GET, POST…), and the server sends back a response with a status code and data.

APIGot it Like the café waiter

Like the waiter in a café: you never go into the kitchen. You tell him “a coffee with milk and a msemmen”, he goes to the kitchen and brings back your order.

An API is a way for one program to talk to another. It tells you what you can ask for, how to ask, and what you’ll get back, without knowing what happens inside.

RESTGot it Like the café menu

Like a café menu: every item has a name (tea, coffee, juice), and there are only a few known actions: order, add, change, cancel.

REST is a common way to design an API: every thing has a URL (a resource), and you use HTTP verbs on it: GET to read, POST to add, PUT to update, DELETE to remove.

JSONGot it Like mum’s shopping list

Like the shopping list your mother writes for you: bread 4, tea 1, sugar 2 kilos. Every item with its name and how much.

JSON is a text format that organises data as keys and values (key: value). It’s easy for people to read and for machines to parse, which is why almost every API uses it.

EndpointGot it Like the counters at the town hall

Like the counters at the local administration office: one for the national ID card, one for civil records. Each does one job, and you need the right one.

An endpoint is a specific URL in an API that does one job. Each endpoint has a method (GET, POST…) and returns specific data.

Status codeGot it Like the shopkeeper’s answer

Like the corner shopkeeper’s answers: 200 “here you go”, 404 “we don’t have it”, 401 “pay first”, 500 “the fridge broke”, and that problem is his, not yours.

A status code is a number the server returns with every response to tell you what happened: 200 all good, 404 not found, 500 a server error.

CORSGot it Like the residence guard

Like the guard at a residence gate: he doesn’t let just anyone in. A resident has to tell him “this person is with me”.

CORS is a browser rule that blocks a site from fetching data from another domain, unless that domain’s server allows it with the Access-Control-Allow-Origin header.

Frontend

HTMLGot it Like the walls of a house

Like building a house: walls, doors and a roof. It isn’t painted or furnished yet, but the house is standing.

HTML is the language that builds the structure of a web page: headings, paragraphs, images, buttons. Everything sits inside a tag.

CSSGot it Like paint and zellige

If HTML is the structure of the house, CSS is the paint, the zellige and the furniture. Same house, but everyone decorates it to their taste.

CSS is the language that styles HTML: colours, fonts, spacing, and how the page looks on a phone or a computer.

DOMGot it Like the family tree

Like a family tree: grandparents, then their children, then the grandchildren. To change someone, you find them by their place in the tree.

The DOM is the browser’s in-memory picture of an HTML page, shaped like a tree of elements. JavaScript works on the DOM to change what’s on screen without reloading the page.

ComponentGot it Like the brick mould

Like a brick mould: you don’t shape every brick by hand. You make the mould once and fill it as many times as you need.

In React, a component is a piece of the interface (a button, a card, a menu) with its own code and style. You build it once and reuse it in many places.

StateGot it Like the stadium scoreboard

Like the scoreboard at the stadium: every time a goal goes in, the number changes and the board updates itself. Same match, only the score moved.

State is data a component keeps and that changes over time (like how many times a button was clicked). When state changes, React redraws the component on its own.

PropsGot it Like the chef’s order

Like the order the chef hands you in a restaurant: “three meat tagines”. You cook what you were told; you don’t change the order.

Props are the values a parent component passes to a child component. The child reads them but never changes them: if something must change, the parent changes it.

useEffectGot it Like the light in each room

Like switching on the light when you walk into a room: you don’t flick it every minute, only when you change rooms.

useEffect is a React hook that runs some work after a component appears: fetching data from an API, starting a timer… Its dependency array says when to run it again.

Data

DatabaseGot it Like the town hall archive

Like the archive at the town hall: every file in its place with a number, so the clerk finds yours in a minute because everything is in order.

A database is an organised place to store data so you can read, add, update and delete it quickly, even when there are millions of rows.

SQLGot it Like asking the shopkeeper

Like telling the shopkeeper: “give me every vegetable under 10 dirhams”. You say what you want; he knows where it is.

SQL is the language for talking to a relational database: you say what you want (SELECT), from where (FROM) and under which condition (WHERE).

SQL JOINGot it Like the shopkeeper’s credit notebook

Like the corner shopkeeper’s credit notebook: one page lists the neighbours and their house numbers, another lists debts by house number. JOIN puts them together: who owes what.

JOIN combines the rows of two (or more) tables using a shared column. INNER JOIN keeps only what’s in both; LEFT JOIN keeps everything from the left table.

Primary keyGot it Like the national ID number

Like the national ID card number (CIN): plenty of people are called Mohamed Alaoui, but no two share a CIN. That’s how you know exactly who is who.

A primary key is a column (or several) that uniquely identifies each row in a table. It can’t repeat and can’t be empty.

ORMGot it Like the court interpreter

Like an interpreter in court: you speak your language, he translates for the judge, and brings the answer back in yours.

An ORM is a library that lets you work with a database using your language’s objects (JavaScript, Python…) instead of writing SQL by hand. It translates to SQL for you.

DevOps

DockerGot it Like the containers at Tanger Med

Like the containers at the port of Tanger Med: whatever is inside, they all have the same size, are lifted by the same crane and fit on any ship.

Docker packs your application with everything it needs (Node version, libraries, settings) into a single image. That image runs the same way on any machine.

ContainerGot it Like baghrir from one recipe

If the image is the baghrir recipe, a container is the baghrir cooked in front of you. One recipe, as many as you want.

A container is a running copy of a Docker image. You can start many containers from the same image, each isolated from the others.

Environment variableGot it Like the café wifi password

Like the wifi password in a café: it isn’t printed on the menu everyone reads, you ask the waiter. Same menu, but the password can change.

An environment variable is a value kept outside the code (a database password, an API key) so it never ends up on GitHub, and can change per environment (dev, prod).

DeployGot it Like Ramadan harira for the neighbours

Like cooking harira at home and sharing it with the neighbours during Ramadan: before, only you had it; now everyone can have a bowl.

Deploying means putting your code on a server so the site or app is available to people on the internet, not just on your computer.

CI/CDGot it Like the car’s technical inspection

Like the technical inspection before your car goes back on the road: if everything passes, you get the paper and drive on. If not, you fix it first.

CI/CD is automation: every time you push, the tests run on their own (CI), and if everything passes, the code goes to production on its own (CD).

Security

JWTGot it Like the Mawazine wristband

Like the wristband at the Mawazine festival: when the guard sees it on your wrist, he lets you in without asking your name. And you can’t fake it, because it carries a special seal.

A JWT (JSON Web Token) is a signed token the server gives you when you log in. You send it back with every request, and the server checks the signature without going back to the database.

HashingGot it Like lemon juice

Like lemon juice: from a lemon you get juice, but from the juice you can never get the lemon back. And the same lemon always gives the same taste.

Hashing turns text (such as a password) into a fixed string of characters, and you can’t get the original text back from it. Passwords should always be stored hashed with a salt (bcrypt, argon2).

Authentication / authorizationGot it Like passport and boarding pass

At Mohammed V airport: at passport control they check who you are. At the gate they check your boarding pass: whether you’re allowed on this plane.

Authentication checks who you are (logging in with an email and password). Authorization decides what you’re allowed to do next (an admin can delete, a regular user can’t).
