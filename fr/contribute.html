Un terme manque ? Ajoutez-le.

Tous les termes vivent dans un seul fichier, tools/terms.mjs, en trois langues. Ajoutez le vôtre en quatre étapes.

Le code est sur GitHub : github.com/ElFarisssaid19/qamous-dev

  1. Forkez le dépôt sur GitHub, puis clonez votre fork.

    git clone https://github.com/<you>/qamous-dev.git

  2. Ajoutez votre terme dans tools/terms.mjs, en arabe, en français et en anglais.

  3. Régénérez les pages.

    node tools/build.mjs

  4. Faites un commit, un push, puis ouvrez une pull request.

    gh pr create
